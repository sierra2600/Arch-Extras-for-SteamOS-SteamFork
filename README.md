# SteamOS-pacman-helper
This is a specialized script for installing pacman packages on SteamOS, once the said package is installed, this script WILL REMOVE ITSELF FROM EXISTENCE as tinkering too much in another realm that is not SteamOSs already existing mirrors could have potential of someone having a bad day

`curl -fsSL https://raw.githubusercontent.com/sierra2600/Arch-Extras-for-SteamOS-SteamFork/refs/heads/main/InstallExtra.sh | sh`
